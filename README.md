# auditrepo

Audit timestamps and repo durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/auditrepo/

## Install / run

```bash
git clone https://github.com/theworker02/auditrepo.git
cd auditrepo
node src/cli.js
node --test
```
